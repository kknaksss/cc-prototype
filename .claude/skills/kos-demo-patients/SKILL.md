# KOS 데모 환자 채우기 · 지우기

시술 현황판 데모를 하려면 KOS 데모 지점에 그날 고객이 있어야 한다. 이 스킬은 **공개 API 로 예약까지** 만든다(국적 칸 · 시간 · 국적 · 가상 이름).
스크립트 = `procedure/tools/kos_demo_patients.py`(stdlib 만 · `python3` 로 실행).

## 언제

- 데모 **전날 · 당일**: 그날 4층 국적 칸마다 슬롯당 2명 채우기(`create`)
- 데모가 끝난 뒤: 그날 우리가 만든 데모 예약 지우기(`delete`)
- 지금 몇 건 있나: `list`

## 안전 규칙 — 반드시

1. **데모 테넌트만.** env = `procedure/.env` 의 `KOS_OPEN_API_BASE` · `KOS_OPEN_API_KEY`(데모 키 — ax-clinic-project `KOS_API_tenent_dev` 값) · `KOS_ZONE_ID`(4층).
   **운영 명동점 키(`KOS_API_tenent`)는 절대 쓰지 않는다.** 스크립트는 직원 목록에 데모 표식 계정(KOS-DEMO)이 없으면 운영으로 보고 멈춘다
2. **값 출력 금지** — 키 · 토큰 · 비밀번호를 터미널 · 보고 · 커밋에 내지 않는다(스크립트는 상태 · 오류 이름만 찍는다)
3. **기존 일정 손대지 않기** — 수정 · 취소는 우리가 만든 예약에만
4. **우리가 만든 것 = 예약 메모 `[ccc 데모 <YYYY-MM-DD>]` 로 시작** + 기록 파일의 scheduleId. `list` · `delete` 는 메모 표식만 보고, 예약 상태(RESERVED)가 아닌 것(접수 이후로 진행한 것)은 지우지 않는다
5. 이름은 스크립트 안 가상 이름(국적별 흔한 형태 조합 · 실존 인물 · 직원 이름 아님) · 연락처 없음
6. 실제 생성 · 삭제 전에 **사용자(또는 코디) 확인**을 받는다 — 데모 지점도 공유 환경이다

## 순서

1. **그룹 조회 · 계획**: `python3 procedure/tools/kos_demo_patients.py create --date <날짜> --dry-run --out <계획.md>`
   — 4층 국적 칸 · 정원(지금 3명/30분) · 그날 열린 슬롯(기본 예약 규칙 · 30분) · 이미 있는 우리 예약을 보고 **정원을 넘지 않게** 모자란 만큼만 계획
2. **1건 먼저 확인**: `--groups 중화권 --per-slot 1` 처럼 작게 만들어 `list` 로 그 칸 · 시간 · 국적이 맞는지 본다(KOS 4층 예약 화면 그 칸에 뜨는지)
3. **전체**: `create --date <날짜> --out <결과.md>`
4. **재조회**: `list --date <날짜> --out <목록.md>` — 칸별 수 확인 · 기록 파일을 남긴다(지울 때 대조용)
5. 지우기: `delete --date <날짜>`(확인 프롬프트 · 자동이면 `--yes`) → `list` 로 0 확인

## 칸 ↔ 국적 (4층 예약 그룹)

| 칸(예약 그룹) | 국적(슬롯 안에서 돌려가며) |
|---|---|
| 국내 | KR |
| 중화권 | CN · TW |
| 영미권 | US · GB · AU · CA |
| 일본 | JP |
| 기타 | TH · VN |

- 나머지 그룹(리프팅 · 레이저 · 필러 · 스킨부스터 · 보톡스 · 제모 · 후관리 · 수액/체형)은 **시술 칸**이라 쓰지 않는다
- 칸 지정 = 공개 `reserveV2`(`occupiedResources[].reservationGroup`). `reserveByTimeSlot` 은 칸을 못 정해 전부 기본 칸(국내)에 들어간다 — 2026-10-22 실수

## 한계 — KOS 화면 몫

- **재내원 안 됨**: 공개 API 로 새로 만든 내원객은 KOS 가 모두 첫내원으로 저장한다. 재내원은 기존 내원객 id 로 예약해야 하는데 기존 데이터라 하지 않는다
- **카드로 띄우기**: 시술 현황판 카드 = 시술 대기 이상 + 방 배정 + 시술 작업(SPEC-003 §5.1). 공개 API 에 접수 · 수납(시술 작업 생성) · 방 배정이 없다. 데모 직전 카드로 쓸 고객만 **KOS 데모 화면에서**:
  1. 예약 → **접수**
  2. (상담) → **수납**에서 시술 추가 — 결제 전이어도 카드는 뜬다(「수납 필요」)
  3. **시술 대기** + **방 배정**(「방 배정」 작업)
  4. 10초 안에 현황판 카드
- 슬롯: 기본 예약 규칙의 **지금 열린** 슬롯만 계획한다(당일엔 지난 · 마감 슬롯이 빠짐 — 당일 마감 규칙)

## 기록

결과는 `--out` 경로(markdown 표: 그룹 · 시간 · 국적 · 가명 · 상태 · scheduleId). 오케스트레이션 기록 예: `orchestration/work/myeongdong-poc-v2/demo-patients-<날짜>.md`.
지우기 API(직접 할 때) = `POST {KOS_OPEN_API_BASE}/schedule/open/v1/commands/cancel-reservation {scheduleId, reason:"CANCELED"}`.
